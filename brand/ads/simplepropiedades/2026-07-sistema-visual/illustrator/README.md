## Reglas de layout

- **Sin badge** superior
- Títulos **grandes** (impacto)
- Hero **oversized** (puede invadir zonas inseguras)
- Texto + CTA **solo** en zona segura Meta
- Cards casi cuadradas, íconos stroke limpios (sin glow)
- Fondo atmosférico: blobs indigo + dots
